# Benchmarking Projects

## Serial Bowl 2025
A 16-algorithm single-elimination championship tournament that pits serial/parallelized algorithms against each other with the grand finalists
receiving a thorough comparison of weak/strong scaling on both the GCC & ICPC compilers. The final presentation can be found here: https://chrisso.tv/pdf/SerialBowl2025.pdf

## OS Benchmarking
An exploration into the basic techniques of benchmarking, specifically in regards to basic iterative loops, system call overhead,
and latency/throughput of paired processes. The full report can be found here: https://chrisso.tv/pdf/Benchmarking.pdf
